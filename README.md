# GeekSupport Website Redesign

A modern, professional redesign of the GeekSupport website using HTML, Tailwind CSS, and JavaScript.

## Features

### 🎨 Modern Design
- Clean, professional UI with gradient backgrounds
- Responsive design that works on all devices
- Smooth animations and transitions
- Modern typography and color scheme
- Advanced hover effects and micro-interactions

### 📱 Responsive Layout
- Mobile-first approach
- Tablet and desktop optimized
- Collapsible mobile navigation
- Touch-friendly interface
- Optimized for all screen sizes

### ⚡ Interactive Elements
- Smooth scrolling navigation
- Hover effects on cards and buttons
- Animated entrance effects
- Mobile menu toggle
- Floating background elements
- Back-to-top button
- Progress indicator
- Contact form with validation
- Newsletter signup
- Industry card interactions

### 📝 Forms & Functionality
- Contact form with real-time validation
- Newsletter subscription
- Form submission handling
- Success/error message displays
- Email format validation
- Required field validation

### 🛠️ Technical Stack
- **HTML5**: Semantic markup and accessibility
- **Tailwind CSS**: Utility-first CSS framework
- **JavaScript**: Vanilla JS for interactivity
- **Font Awesome**: Icon library
- **Google Fonts**: Professional typography

## Project Structure

## Development

To run this project locally:

1. Clone or download the files
2. Open `index.html` in your web browser
3. No build process required - works directly in browser

## Customization

The design uses Tailwind CSS classes that can be easily customized:

- Colors: Modify gradient classes and color utilities
- Spacing: Adjust padding/margin classes
- Typography: Change font sizes and weights
- Animations: Modify transition durations and effects
